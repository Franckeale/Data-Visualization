# Exemples prévus

À créer : courbes et barres avec Matplotlib ; distributions, nuages de points et corrélations avec Seaborn ; visualisation interactive avec Plotly ; activité de service client sur données synthétiques.

Chaque exemple devra inclure sa question, ses données documentées, son code, ses instructions d’exécution, un graphique et une interprétation. Aucun exemple exécutable n’est encore présent.
