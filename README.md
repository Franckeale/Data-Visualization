# Data Visualization — Franck Eale

Portfolio en construction consacré à l’exploration des données et à la communication visuelle avec **Python, pandas, Matplotlib, Seaborn et Plotly**.

L’objectif est de réunir progressivement mes travaux pédagogiques, leur code et des graphiques accompagnés d’explications. Ce dépôt démarre par une documentation et une organisation ; il ne contient pas encore de notebooks ni de visualisations exécutables.

## Documentation attendue pour chaque travail

Chaque projet ou exemple devra préciser :
1. La question étudiée.
2. La source des données et les droits d’utilisation.
3. Les étapes de préparation.
4. Le code et les instructions d’exécution.
5. Les graphiques et une courte interprétation.
6. Les limites de l’analyse.
